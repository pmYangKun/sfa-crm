# Quickstart: MCP 开放平台

**Feature**: 005-mcp-open-platform

本文覆盖两件事：**开发者怎么在本地把它跑起来验证**，以及**部署时不能漏的那两处**。

---

## 一、本地起跑

### 前置

沿用仓库既有方式（`start.bat` 一键起前后端）。**无需数据库迁移**——本仓库无 alembic，新表由 `SQLModel.metadata.create_all()` 在服务启动时自动创建。

老库升级注意：5 个新增配置项由 `init_db` **幂等补 key**（缺失则插入，已存在不覆盖）。这是 spec 002 踩过的坑——若用 short-circuit 判断"已初始化就整体跳过"，老库永远拿不到新键。

### 冒烟三步

```
1. 领密钥      POST /api/v1/mcp/tokens  {"persona":"manager"}
2. 列工具      带上 Bearer 调 MCP 端点的工具列举 → 应返回 9 个
3. 调一个      调 scan_team_warnings → 应返回非空结果
```

第 2 步返回 9 个、且其中不含任何 `navigate_*`，说明过滤生效。

## 二、验收清单（对应 spec 的 SC）

### SC-003 身份可见范围（**最该先验的一条**）

```
用 sales 密钥调 scan_team_warnings   → 记下返回的线索集合 A
用 manager 密钥调 scan_team_warnings → 记下返回的线索集合 B
断言：A ⊂ B，且 A ≠ B
```

这条不过，本 feature 的核心价值就不成立。

### SC-004 五客户端接入

**必须逐个实测，不能靠推断。** WorkBuddy / Claude Code / Claude Desktop / Cursor / Codex 各配一遍，各问一句，各截一张图。

Codex 的凭证走环境变量而非配置文件内联，其步骤与其他四个不同，单独验。

### SC-005 演示重置后密钥存活

```
领一把密钥 → 调通一次 → 手工触发一次演示数据重置 → 再调一次
断言：第二次仍然成功
```

对应 FR-030。`demo_reset_service` 是显式删除列表，`McpToken` 不在其中即可满足——**这条测试是防未来有人把它加进去**。

### SC-006 限流

单密钥连续超过每分钟额度 → 应返回 429 且文案可读。

同时验证**不串桶**：MCP 打满额度后，内置 Copilot 聊天仍可正常使用（两者限流 key 必须独立）。

### SC-007 移动端等价

PC 与 Mobile 两套 Playwright，覆盖：领密钥 → 展开配置 → 复制 → 查看工具目录 → 演示区。**任何"请到电脑上操作"的路径都是返工项。**

### FR-027 注入消毒

在演示数据里写一条含伪装指令的跟进记录 → 通过 `get_followup_history` 取回 → 断言该文本被不可信标记包裹且长度受限。

## 三、部署（两处不能漏）

### 1. nginx 流式缓冲

MCP 走流式响应。既有 `/api/v1/` location **必须**加 `proxy_buffering off`。

**漏了的表现不是"不好看"，而是工具调用长时间无响应**——比 2026-05-19 那次（AI 回复不流式）更难定位，因为它看起来像超时而非渲染问题。

验证手法：调一次工具，观察响应是否逐步到达而非一次性返回。

`docs/deploy.md` 的 nginx 模板须同步更新。

### 2. 演示区凭证

演示区所用密钥由**服务端环境变量**注入，随其他 secrets 一同管理。

**部署自检：** 打开 `/open` 首页 → 查看页面源码与网络请求 → 确认任何位置都搜不到该密钥（FR-021）。这一条建议做成部署后的固定检查项。

## 四、常见问题定位

| 现象 | 大概率原因 |
|---|---|
| 客户端连得上但列不出工具 | 协议协商阶段的能力声明有问题，或鉴权在列举阶段被拦 |
| 工具调用长时间无响应 | nginx 缓冲未关（见上） |
| 两种身份返回一样的数据 | 密钥换身份后未把 user 传进 `execute_tool`，DataScope 落空 |
| 用着用着突然全部失效 | 演示重置误删了密钥表，检查 `demo_reset_service` 的删除列表 |
| 一聊天就提示请求过多 | 限流 key 与内置 Copilot 串桶了，两者必须独立计量 |
| 某一个客户端连不上，其余正常 | 该客户端的凭证写法差异（尤其 Codex 的环境变量方式） |
